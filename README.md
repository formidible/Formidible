A small Rust CLI for managing packages directly inside a NixOS configuration.

### What it does

- Add packages
- Remove packages
- Edit `configuration.nix`
- Create backups
- Preview changes with `--dry-run`
- Run `nixos-rebuild` with `--rebuild`
